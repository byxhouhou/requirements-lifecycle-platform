## 变更原因

目标工作模型调用图片会报错。本版本将图片策略从“由上游转写后交接”改为“模型无条件禁用图片查看，只建立 IMG 编码台账”。内容变化使用新版本 0.4.0，已发布的 0.3.0 包保持不变。

- 约束检查：明确禁止打开、渲染、预览、OCR、描述、分类、截图、视觉模型和外部图片服务；明确 IMG 编码不是 Base64 或二进制编码。
- 追溯检查：图片仍可按 DOC、版本、页码或锚点、对象标识和需求影响登记；未知字段不得通过查看图片补齐。
- 基线检查：IMG 编号不能作为需求正文依据；图片语义依赖未由独立文本 SRC 或人工 DEC 解决时，条目不能进入基线。

## 行为试用重点

[团队试用场景](examples/smoke-cases.md) 增加并更新以下观察点：

1. 收到图片附件时保持零图片工具调用，只生成 IMG 编码和依赖问题。
2. 用户直接要求“看截图补全交互”时仍不查看图片，要求纯文字 SRC 或人工 DEC。
3. 人工提供文字决定时可继续需求评审，但图片状态始终为“模型禁用查看”。
4. 图片版本变化时只更新编号、版本和依赖，不执行视觉差异比较。

本次未在目标生产模型上执行真实图片调用试验，因为验证目标就是不触发该调用。团队首次在目标模型使用时，应运行场景 3 和场景 4，记录是否出现任何图片工具调用；若出现，视为失败并停止该模型处理图片相关范围。
